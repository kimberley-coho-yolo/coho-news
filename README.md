# Coho Group Technology Roadmap News

Staff news site for the Microsoft 365 migration, ISO 27001 and enterprise architecture program.
Built with Jekyll and hosted free on GitHub Pages.

- **Posting an update:** see [HOW-TO-POST.md](HOW-TO-POST.md)
- **Site settings** (contact email, question form): `_config.yml`
- **Timeline page:** `key-dates.md`
- **News posts:** `_posts/` (file name must start with the date, e.g. `2026-11-23-title.md`)
- **Template for new posts:** `_drafts/example-update.md` (drafts are never published)
